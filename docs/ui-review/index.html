Có gì mới trong đợt này

  • Mọi agent có đủ 3 quyền: Chỉ hỏi, Sửa code · hỏi trước, Tự động.
  • Sửa code mặc định làm thẳng trong thư mục; Giữ / Hoàn tác từng đoạn. Bản nháp tạo từ nhánh tự chọn.
  • Dòng trạng thái ngay trên ô chat, nút Dừng (Esc), con trỏ nhấp nháy khi agent đang viết.
  • Chép / Chép Markdown dưới mỗi câu trả lời, nút Chép trên khối code. Thanh cuộn mảnh.
  • Hết đứng app sau mỗi lượt: lệnh Git chạy nền, lượt Chỉ hỏi không tải diff.

Cần biết khi review

  • Ảnh chụp ở chế độ mock (dữ liệu mẫu, agent giả), cửa sổ 1440×900.
  • Nút thu nhỏ / phóng to / đóng chỉ chạy trong app desktop.
  • Tên model trong menu là dữ liệu mẫu; app thật đọc từ chính CLI.
  • Đánh dấu chỉ lưu trong trình duyệt của bạn. Xong thì bấm "Chép kết quả review" rồi dán cho Claude.
